게시판

다른 집사들의 분석과 별점을 모았어요.

여러 사람의 분석 횟수와 별점을 모으려면 무료 서버(Supabase)를 연결해야 해요.

  1. supabase.com 에서 무료 프로젝트를 만들어요.
  2. SQL Editor 에 supabase_setup.sql 내용을 붙여넣고 Run 해요.
  3. Project Settings → API 의 Project URL과 anon public key를 복사해요.
  4. index.html 위쪽 CONFIG 의 두 값에 붙여넣고 다시 배포해요.

anon key는 공개돼도 되는 키예요. 쓰기는 SQL에서 만든 함수로만 가능해요.

서비스 안내

이 서비스는

사료·간식 성분표를 읽어 고양이에게 좋은 성분과 피해야 할 성분을 알려드리는 참고용 도구예요. 진단·처방을 대신하지 않아요.

개인정보

  • 회원가입 없이 써요. 기기에는 익명 번호만 저장돼요.
  • 성분표 사진은 서버에 저장하지 않아요. Claude 화면 안에서 열면 Claude가 사진 속 글자를 읽고, 그 밖에서는 기기 안에서 글자를 인식해요.
  • 게시판에는 제품명·점수·별점만, 의견 게시판에는 직접 쓴 글이 공개돼요.
  • 서비스 개선을 위해 방문·화면 이동·분석 횟수 같은 이용 통계를 익명으로 수집할 수 있어요(Google Firebase Analytics).
